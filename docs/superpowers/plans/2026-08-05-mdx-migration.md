# MDX Migration + /docs Section Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate the blog's rendering pipeline from `react-markdown` to `@next/mdx` with `rehype-pretty-code`/Shiki for better code block quality, and add a `/docs` route for concept-type posts (separate folder from tech posts).

**Architecture:** MDX files live in `src/content/posts/{tech,concepts}/` and are loaded via dynamic `import()` in Server Components. `@next/mdx` + `rehype-pretty-code` + `rehype-slug` handles compilation at build time. A one-shot migration script converts the existing 11 `.md` files. The `/docs` page uses `useSearchParams` (same pattern as `/tags`) to show category cards or a filtered post list.

**Tech Stack:** `@next/mdx`, `@mdx-js/react`, `rehype-pretty-code`, `shiki`, `rehype-slug`, `@types/mdx`

## Global Constraints

- Next.js 16 App Router, TypeScript, Tailwind v4
- Dev server runs `next dev` (no `--turbo` flag) — Turbopack is NOT active
- `next.config.mjs` must be converted to ESM (`export default`)
- `mdx-components.tsx` must live at the project root (Next.js App Router requirement)
- `socialImage` in MDX metadata stores a raw Supabase path (e.g., `'20240724_01/file.webp'`) — URL resolution via Supabase client happens in `content.ts`, same as current `file.ts`
- `PostMetaDataType` adds `categories?: string[]` — ordered array representing category depth (e.g., `['react', 'hooks']`); optional so tech posts don't need it
- `socialImage` in MDX metadata stores a raw Supabase path (e.g., `'20240724_01/file.webp'`) — URL resolution via Supabase client happens in `content.ts`, same as current `file.ts`

- [ ] **Step 1: Write migration script**

```js
// scripts/migrate-to-mdx.mjs
import fs from 'fs';
import path from 'path';
import matter from 'gray-matter';
import { fileURLToPath } from 'url';

const __dirname = path.dirname(fileURLToPath(import.meta.url));
const SRC = path.join(__dirname, '../public/posts');
const DEST = path.join(__dirname, '../src/content/posts/tech');

fs.mkdirSync(DEST, { recursive: true });

const files = fs.readdirSync(SRC).filter((f) => f.endsWith('.md'));

for (const file of files) {
  const raw = fs.readFileSync(path.join(SRC, file), 'utf-8');
  const { data, content } = matter(raw);

  const { title, description, date, tags, socialImage, timestamp } = data;

  const tagsArray = Array.isArray(tags) ? tags : [];
  const tagsJson = JSON.stringify(tagsArray);

  const mdxContent = `export const metadata = {
  title: ${JSON.stringify(title ?? '')},
  description: ${JSON.stringify(description ?? '')},
  date: ${JSON.stringify(date ?? '')},
  tags: ${tagsJson},
  socialImage: ${JSON.stringify(socialImage ?? null)},
  timestamp: ${timestamp ?? 0},
};

${content.trim()}
`;

  const outFile = file.replace('.md', '.mdx');
  fs.writeFileSync(path.join(DEST, outFile), mdxContent, 'utf-8');
  console.log(`✓ ${outFile}`);
}

console.log(`\nMigrated ${files.length} files to ${DEST}`);
```

```typescript
// src/utils/content.ts
import fs from 'fs';
import path from 'path';
import supabase from '@/supabaseClient';
import { SUPABASE_BUCKET_NAME } from '@/constants/common';
import { PostFileType, PostMetaDataType } from '@/types/post';

const TECH_DIR = path.join(process.cwd(), 'src/content/posts/tech');
const CONCEPTS_DIR = path.join(process.cwd(), 'src/content/posts/concepts');

const resolveThumbnail = (socialImageName: string | null): string => {
  const {
    data: { publicUrl },
  } = supabase.storage.from(SUPABASE_BUCKET_NAME).getPublicUrl(socialImageName || 'default.png');
  return publicUrl;
};

const loadFromDir = async (dir: string, section: 'tech' | 'concepts'): Promise<PostFileType[]> => {
  const files = fs.readdirSync(dir).filter((f) => f.endsWith('.mdx'));

  return Promise.all(
    files.map(async (file) => {
      const slug = file.replace('.mdx', '');
      const mod =
        section === 'tech'
          ? await import(`@/content/posts/tech/${slug}.mdx`)
          : await import(`@/content/posts/concepts/${slug}.mdx`);

      const rawMeta: PostMetaDataType = mod.metadata;

      return {
        fileName: slug,
        data: {
          ...rawMeta,
          socialImage: resolveThumbnail(rawMeta.socialImage),
        },
      };
    }),
  );
};

export const getTechPostMetadataList = (): Promise<PostFileType[]> => loadFromDir(TECH_DIR, 'tech');

export const getConceptsPostMetadataList = (): Promise<PostFileType[]> =>
  loadFromDir(CONCEPTS_DIR, 'concepts');

export const getAllPostMetadataList = async (): Promise<PostFileType[]> => {
  const [tech, concepts] = await Promise.all([
    getTechPostMetadataList(),
    getConceptsPostMetadataList(),
  ]);
  return [...tech, ...concepts];
};
```

**Note on code block rendering:** `rehype-pretty-code` processes code blocks at the remark/rehype AST level — the fenced code blocks in MDX become pre-rendered `<pre><code>` with inline Shiki styles BEFORE React sees them. The `pre` override in `mdx-components.tsx` intercepts this. There is no `code` renderer needed for fenced blocks.

- [ ] **Step 1: Rewrite `src/components/posts/CodeBlock.tsx`**

The old `CodeBlock` took `children` (raw string) + `match` (regex). The new version wraps a Shiki `<pre>` and copies text via `innerText`:

```tsx
// src/components/posts/CodeBlock.tsx
'use client';

import { useRef, useState } from 'react';
import CopyIcon from '../icons/CopyIcon';
import CheckIcon from '../icons/CheckIcon';

const CodeBlock = ({ children, ...props }: React.HTMLAttributes<HTMLPreElement>) => {
  const [showCopy, setShowCopy] = useState(false);
  const [isCopy, setIsCopy] = useState(false);
  const ref = useRef<HTMLPreElement>(null);

  const handleCopy = () => {
    const text = ref.current?.innerText ?? '';
    navigator.clipboard.writeText(text);
    setIsCopy(true);
  };

  const handleMouseEnter = () => setShowCopy(true);
  const handleMouseLeave = () => {
    setShowCopy(false);
    if (isCopy) setTimeout(() => setIsCopy(false), 500);
  };

  return (
    <div
      className="relative"
      onMouseEnter={handleMouseEnter}
      onMouseLeave={handleMouseLeave}
      onFocus={handleMouseEnter}
      onBlur={handleMouseLeave}
    >
      <pre ref={ref} {...props}>
        {children}
      </pre>
      <button
        type="button"
        onClick={handleCopy}
        className={`${showCopy ? 'block' : 'hidden'} absolute top-3 right-3 rounded border border-greyCopy p-1 hover:bg-greyCopy`}
      >
        {isCopy ? <CheckIcon className="text-darkText" /> : <CopyIcon className="text-darkText" />}
      </button>
    </div>
  );
};

export default CodeBlock;
```

// mdx-components.tsx
import type { MDXComponents } from 'mdx/types';
import CodeBlock from '@/components/posts/CodeBlock';
import MarkdownImage from '@/components/posts/MarkdownImage';

export function useMDXComponents(components: MDXComponents): MDXComponents {
  return {
    ...components,
    pre: ({ children, ...props }) => <CodeBlock {...(props as React.HTMLAttributes<HTMLPreElement>)}>{children}</CodeBlock>,
    blockquote: ({ children, ...props }) => (
      <blockquote
        className="my-4 border-l-4 border-l-[#8491D9] bg-[#F8F9FA] p-4 dark:bg-[#282C34]"
        {...props}
      >
        {children}
      </blockquote>
    ),
    a: ({ href = '', children, ...props }) => {
      if (href.match('http')) {
        return (
          <a
            href={href}
            target="_blank"
            rel="noopener noreferrer"
            style={{ color: '#8491D9', fontWeight: 700, wordBreak: 'break-word', textDecoration: 'underline' }}
            {...props}
          >
            {children}
          </a>
        );
      }
      return <a href={href} {...props}>{children}</a>;
    },
    ol: ({ children, ...props }) => (
      <ol style={{ listStyle: 'decimal', marginLeft: '1rem' }} {...props}>
        {children}
      </ol>
    ),
    ul: ({ children, ...props }) => (
      <ul style={{ listStyle: 'disc', marginLeft: '2rem', paddingBottom: '0.5rem' }} {...props}>
        {children}
      </ul>
    ),
    hr: (props) => <hr className="text-grey dark:text-greyLight" {...props} />,
    strong: ({ children, ...props }) => (
      <strong
        style={{
          fontFamily: `Monaco, Spoqa Han Sans Neo, Noto Sans KR, sans-serif`,
          fontWeight: 600,
          verticalAlign: '0.5px',
          fontSize: '1rem',
        }}
        {...props}
      >
        {children}
      </strong>
    ),
    img: (props) => <MarkdownImage {...props} />,
  };
}

### Task 7: `/docs` Route

**Files:**
- Create: `src/app/docs/page.tsx`
- Create: `src/components/docs/DocsCategories.tsx`

**Interfaces:**
- Consumes:
  - `getConceptsPostMetadataList(): Promise<PostFileType[]>` from `@/utils/content`
  - `useSearchParams().get('c')` — comma-separated category path, e.g. `'react,hooks'` for depth-2
- Produces: a single unified list mixing sub-category rows and post rows at the current depth. No card grid — folder items and post items share one vertical list with clear visual distinction. Breadcrumb for navigation up.

**Category derivation rule:** a post's `categories` array drives drill-down. `categories: ['react', 'hooks']` → appears as sub-category row at `/docs` (react), as post row at `/docs?c=react,hooks`. A post with `categories: ['react']` appears directly as a post row at `/docs?c=react`.

**Visual design:**

```
DOCS > react                         ← breadcrumb

┌─────────────────────────────────┐
│ 📁  hooks                   3 → │  ← folder row: bolder, right chevron
├─────────────────────────────────┤
│ 📁  state                   1 → │
├─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┤  ← subtle divider between folders/posts
│ React Query 도입하기              │  ← post row: title + date right-aligned
│                      2024-07-24 │
├─────────────────────────────────┤
│ context API로 코드 개선            │
│                      2024-06-10 │
└─────────────────────────────────┘
```

- Folder rows: `font-bold`, `text-main` on hover, count badge + ChevronRightIcon
- Post rows: regular weight, `text-main` title on hover, date right-aligned in `text-greyCopy`
- Thin border separates each row; subtle `border-l-4 border-main` appears on folder row hover
- Folder rows sort alphabetically above post rows

- [ ] **Step 1: Create `src/components/docs/DocsCategories.tsx`**

```tsx
// src/components/docs/DocsCategories.tsx
'use client';

import Link from 'next/link';
import { useRouter, useSearchParams } from 'next/navigation';
import ChevronRightIcon from '@/components/icons/ChevronRightIcon';
import { PostFileType } from '@/types/post';
import { getFormattedDate } from '@/utils/format';
import { convertSpaceToDash } from '@/utils/format';
import { PAGE_URLS } from '@/constants/url';

const DocsCategories = ({ posts }: { posts: PostFileType[] }) => {
  const searchParams = useSearchParams();
  const router = useRouter();

  const pathParam = searchParams.get('c') ?? '';
  const currentPath = pathParam ? pathParam.split(',') : [];
  const depth = currentPath.length;

  // Posts whose categories prefix matches currentPath
  const postsAtPath = posts.filter((post) => {
    const cats = post.data.categories ?? [];
    return currentPath.every((seg, i) => cats[i] === seg);
  });

  // Posts that end at this depth (no further sub-category)
  const postRows = postsAtPath
    .filter((post) => (post.data.categories?.length ?? 0) <= depth)
    .sort((a, b) => b.data.timestamp - a.data.timestamp);

  // Sub-categories at next depth
  const subCategoryMap = postsAtPath.reduce<Record<string, number>>((acc, post) => {
    const nextSeg = post.data.categories?.[depth];
    if (nextSeg) acc[nextSeg] = (acc[nextSeg] ?? 0) + 1;
    return acc;
  }, {});
  const folderRows = Object.entries(subCategoryMap).sort(([a], [b]) => a.localeCompare(b));

  const navigateTo = (seg: string) => {
    router.push(`/docs?c=${[...currentPath, seg].join(',')}`);
  };

  const navigateToBreadcrumb = (index: number) => {
    if (index < 0) router.push('/docs');
    else router.push(`/docs?c=${currentPath.slice(0, index + 1).join(',')}`);
  };

  return (
    <>
      {/* Breadcrumb */}
      <nav className="mt-8 flex items-center gap-2 text-sm text-greyCopy sm:mt-16">
        <button type="button" className="hover:text-main" onClick={() => navigateToBreadcrumb(-1)}>
          DOCS
        </button>
        {currentPath.map((seg, i) => (
          <span key={seg} className="flex items-center gap-1">
            <span>/</span>
            <button
              type="button"
              className={i === currentPath.length - 1 ? 'font-bold text-main' : 'hover:text-main'}
              onClick={() => navigateToBreadcrumb(i)}
            >
              {seg}
            </button>
          </span>
        ))}
      </nav>

      {/* Unified list */}
      <ul className="mt-6 divide-y divide-greyLight dark:divide-greyCopy">
        {/* Folder rows first */}
        {folderRows.map(([seg, count]) => (
          <li key={seg}>
            <button
              type="button"
              onClick={() => navigateTo(seg)}
              className="group flex w-full items-center justify-between border-l-4 border-transparent
                px-4 py-4 transition-all hover:border-main hover:text-main"
            >
              <span className="flex items-center gap-3">
                <span className="text-greyCopy group-hover:text-main">📁</span>
                <span className="text-base font-bold">{seg}</span>
                <span className="rounded-full bg-greyLight px-2 py-0.5 text-xs text-greyCopy dark:bg-dark">
                  {count}
                </span>
              </span>
              <ChevronRightIcon className="text-greyCopy group-hover:text-main" />
            </button>
          </li>
        ))}

        {/* Post rows */}
        {postRows.map((post) => (
          <li key={post.fileName}>
            <Link
              href={`${PAGE_URLS.POST}/${convertSpaceToDash(post.data.title)}`}
              className="group flex w-full items-center justify-between border-l-4 border-transparent
                px-4 py-4 transition-all hover:border-main"
            >
              <span className="text-base group-hover:text-main">{post.data.title}</span>
              <span className="ml-4 shrink-0 text-sm text-greyCopy">
                {getFormattedDate(post.data.date, 'hyphen')}
              </span>
            </Link>
          </li>
        ))}

        {/* Empty state */}
        {folderRows.length === 0 && postRows.length === 0 && (
          <li className="py-24 text-center text-greyCopy">카테고리를 선택해 주세요</li>
        )}
      </ul>
    </>
  );
};

export default DocsCategories;
```
