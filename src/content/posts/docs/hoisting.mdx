Hoisting은 변수 및 함수 등의 선언이 코드 최상단으로 끌어올려진 것처럼 동작하는 현상이다.
실제로 코드 최상단으로 옮겨지는 것은 아니고, JS 엔진이 코드를 실행할 때 **선언부만 먼저 메모리에 등록**해두기 때문에 발생하는 현상이다.

## var

```javascript
console.log(name); // undefined
var name = '홍길동';
```

var는 **선언과 함께 초기화도 진행**된다.

`var name`이 스코프 최상단으로 끌어올려지면서 `undefined`로 초기화까지 같이 된다. 그래서 선언 전에 변수에 접근해도 에러 없이 `undefined`가 출력된다.

## let/const

```javascript
console.log(age); // ReferenceError: Cannot access 'age' before initialization
let age = 20;
```

`let` / `const`도 선언 자체는 hoisting되지만, **초기화는 실제 코드 라인에 도달했을 때** 이뤄진다.

### TDZ

선언 ~ 초기화 사이 구간을 TDZ(Temporal Dead Zone)라고 부르는데, 이 구간에서 변수에 접근하면 `ReferenceError`가 발생한다.

## 함수 선언문 vs 함수 표현식

```javascript
hello(); // 정상 동작

// 함수 선언문
function hello() {
	console.log('hi');
}

world(); // TypeError: world is not a function

// 함수 표현식
var world = function () {
	console.log('world');
};
```

- **함수 선언문**은 함수 전체가 hoisting돼서 선언 전에 호출해도 동작한다.
- **함수 표현식**은 `var world`만 hoisting되고 함수 할당은 실제 라인에서 이뤄지므로, 호출 시점엔 아직 `undefined`라서 함수처럼 호출하면 에러가 발생한다.
